1.2 高斯消元法

核心思想：通过初等行变换将增广矩阵化为行阶梯形（Row Echelon Form, REF）或简化行阶梯形（Reduced Row Echelon Form, RREF）。

三种初等行变换：

  1. Ri↔RjR_i \leftrightarrow R_jRi​↔Rj​ ——交换两行
  2. kRikR_ikRi​（k≠0k \neq 0k=0）——某行乘以非零常数
  3. Ri+kRjR_i + kR_jRi​+kRj​ ——某行的 kkk 倍加到另一行

三种初等行变换均不改变方程组的解集——这是高斯消元合法性的理论保证。

消元步骤（两阶段）：
┌─ 正向消元（Forward Elimination → REF）
│  1. 选主元（pivot）：当前列中绝对值最大的非零元素（列主元法）
│  2. 交换行，使主元所在行移到当前处理位置
│  3. 用主元消去下面所有行中该列的系数
│  4. 移到下一列，重复直到最后一行
│
└─ 反向代换（Backward Substitution → RREF）
   5. 从最后一个主元开始，从下往上消去上方同列元素
   6. 每个主元归一化为 1（除以自己的值）

主元的选取策略

  • 列主元消去法：在每一列中选取绝对值最大的元素作为主元，通过行交换将其移到对角位置。这能有效减少舍入误差，是数值计算中的标准做法。
  • 全主元消去法：在剩余子矩阵中选取绝对值最大的元素，同时进行行交换和列交换。精度更高但开销更大，考试中极少要求。

1.3 行阶梯形（REF）与简化行阶梯形（RREF）

REF 的三个条件：

  1. 全零行在最下方
  2. 每个非零行的第一个非零元（主元）在上一行主元的右侧
  3. 主元下方全是零

RREF 在 REF 基础上增加： 4. 每个主元等于 111 5. 每个主元所在列的其他元素全为零

1.6 初等矩阵与 LU 分解

初等矩阵：对单位矩阵 III 做一次初等行变换得到的矩阵。左乘初等矩阵等价于对行做相应的初等变换。

三种初等矩阵：

  • 交换矩阵 EijE_{ij}Eij​：EijAE_{ij}AEij​A 交换 AAA 的第 iii 行和第 jjj 行
  • 倍乘矩阵 Ei(k)E_i(k)Ei​(k)：Ei(k)AE_i(k)AEi​(k)A 将 AAA 的第 iii 行乘以 kkk
  • 倍加矩阵 Eij(k)E_{ij}(k)Eij​(k)：Eij(k)AE_{ij}(k)AEij​(k)A 将 AAA 的第 jjj 行的 kkk 倍加到第 iii 行

初等矩阵均可逆。任何可逆矩阵可以分解为初等矩阵的乘积。

LU 分解（方阵，无行交换时）：A=LUA = LUA=LU，其中 LLL 为单位下三角矩阵，UUU 为上三角矩阵。这是高斯消元的矩阵形式——LLL 记录了消元过程中的乘数，UUU 就是行阶梯形。

求解 Ax=bA\mathbf{x} = \mathbf{b}Ax=b 用 LU 分解分两步：

  1. 前代：解 Ly=bL\mathbf{y} = \mathbf{b}Ly=b（O(n2)O(n^2)O(n2)）
  2. 回代：解 Ux=yU\mathbf{x} = \mathbf{y}Ux=y（O(n2)O(n^2)O(n2)）

比每次对新 b\mathbf{b}b 都做完整消元（O(n3)O(n^3)O(n3)）高效得多。

6.4 惯性定理（Sylvester’s Law of Inertia）

惯性定理：实二次型在任何可逆线性变换下，标准形中的正项个数 ppp（正惯性指数）和负项个数 qqq（负惯性指数）是不变量。

  • ppp = 正特征值的个数
  • qqq = 负特征值的个数
  • p+q=rank(A)p + q = \text{rank}(A)p+q=rank(A)（零特征值的个数 =n−rank(A)= n - \text{rank}(A)=n−rank(A)）

AAA 的可逆 ⟺\Longleftrightarrow⟺ 无零特征值 ⟺\Longleftrightarrow⟺ p+q=np + q = np+q=n。

6.6 矩阵的合同

AAA 与 BBB 合同：存在可逆矩阵 CCC 使得 B=CTACB = C^T A CB=CTAC。

合同关系是等价关系（自反、对称、传递）。合同保持：

  • ✅ 对称性
  • ✅ 惯性指数 (p,q)(p, q)(p,q)
  • ✅ 秩

合同不保持：

  • ❌ 特征值
  • ❌ 行列式

合同与相似的关系：对于实对称矩阵，若 CCC 是正交矩阵（C−1=CTC^{-1} = C^TC−1=CT），则合同等价于相似。正交对角化就是找一个矩阵 QQQ，使得 AAA 既合同于 Λ\LambdaΛ 又相似于 Λ\LambdaΛ。
