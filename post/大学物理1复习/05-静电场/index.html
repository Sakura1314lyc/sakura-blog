5.1 电场强度

5.1.1 基本公式

库仑定律

点电荷 qqq 对试探电荷 q0q_0q0​ 的作用力：

F⃗=14πε0qq0r2r^\vec{F} = \frac{1}{4\pi\varepsilon_0}\frac{qq_0}{r^2}\hat{r}F=4πε0​1​r2qq0​​r^

其中 ε0=8.85×10−12 C2/N ⁣⋅ ⁣m2\varepsilon_0 = 8.85 \times 10^{-12}\,\text{C}^2/\text{N}\!\cdot\!\text{m}^2ε0​=8.85×10−12C2/N⋅m2 为真空介电常数。

电场强度

E⃗=F⃗q0\vec{E} = \frac{\vec{F}}{q_0}E=q0​F​

  • 点电荷的电场：E⃗=14πε0qr2r^\vec{E} = \frac{1}{4\pi\varepsilon_0}\frac{q}{r^2}\hat{r}E=4πε0​1​r2q​r^
  • 电场叠加原理：E⃗=∑E⃗i\vec{E} = \sum \vec{E}_iE=∑Ei​

带电体场强
点电荷E=q4πε0r2E = \frac{q}{4\pi\varepsilon_0 r^2}E=4πε0​r2q​

电偶极子

电偶极矩：p⃗=ql⃗\vec{p} = q\vec{l}p​=ql（方向从 −q-q−q 指向 +q+q+q）

  • 在均匀外电场 E⃗\vec{E}E 中受力矩：M⃗=p⃗×E⃗\vec{M} = \vec{p} \times \vec{E}M=p​×E
  • 电势能：U=−p⃗⋅E⃗U = -\vec{p} \cdot \vec{E}U=−p​⋅E

高斯定理

∮SE⃗⋅dS⃗=1ε0∑q内\oint_S \vec{E} \cdot d\vec{S} = \frac{1}{\varepsilon_0}\sum q_{\text{内}}∮S​E⋅dS=ε0​1​∑q内​

即通过任意闭合曲面的电通量 = 曲面内总电荷的 1/ε01/\varepsilon_01/ε0​ 倍。

应用高斯定理求电场的条件：电场分布具有高度对称性（球对称、轴对称、平面对称）。

5.2 电势

5.2.1 基本公式

电势能与电势

  • 电势能差：Ub−Ua=−q∫abE⃗⋅dl⃗U_b - U_a = -q\int_a^b \vec{E} \cdot d\vec{l}Ub​−Ua​=−q∫ab​E⋅dl（电场力做的功的负值）

  • 正电荷：V>0V > 0V>0；负电荷：V<0V < 0V<0
  • 电势叠加原理：V=∑ViV = \sum V_iV=∑Vi​

电场与电势的关系

  • 一维：Ex=−dVdxE_x = -\frac{dV}{dx}Ex​=−dxdV​

  • 已知电势分布求电场：E⃗=−(∂V∂xi^+∂V∂yj^+∂V∂zk^)\vec{E} = -\left(\frac{\partial V}{\partial x}\hat{i} + \frac{\partial V}{\partial y}\hat{j} + \frac{\partial V}{\partial z}\hat{k}\right)E=−(∂x∂V​i^+∂y∂V​j^​+∂z∂V​k^)

5.3 导体的静电平衡

5.3.1 基本概念

导体达到静电平衡的条件：导体内部电场 E⃗=0\vec{E} = 0E=0，表面 E⃗\vec{E}E 垂直于表面。

静电平衡下导体的性质：

  1. 导体内部 E=0E = 0E=0，导体是等势体
  2. 电荷只分布在导体表面，内部无净电荷
  3. 导体表面的场强 E=σε0E = \frac{\sigma}{\varepsilon_0}E=ε0​σ​（σ\sigmaσ 为面电荷密度）
  4. 表面曲率越大，面电荷密度越大（尖端效应）

空腔导体：

  • 腔内无电荷时：内表面无电荷，腔内 E=0E = 0E=0
  • 腔内有电荷时：内表面感应出等量异号电荷

5.3.2 经典模型

接地导体板

接地 = 电势为零。大地可视为无限大的电荷源/汇。

静电屏蔽

  • 封闭导体空腔可以屏蔽外电场（腔内不受外电场影响）
  • 接地的空腔可以同时对内外进行屏蔽（内外互不影响）

5.5 电介质与高斯定理

5.5.1 基本公式

电介质的极化

  • 无极分子：位移极化
  • 有极分子：取向极化

极化强度与极化电荷

极化强度 P⃗\vec{P}P（单位体积内的电偶极矩之和）。

极化电荷面密度：σ′=P⋅n^\sigma' = P \cdot \hat{n}σ′=P⋅n^（表面法向分量）

电位移矢量

D⃗=ε0E⃗+P⃗\vec{D} = \varepsilon_0\vec{E} + \vec{P}D=ε0​E+P

对各向同性线性介质：D⃗=ε0εrE⃗=εE⃗\vec{D} = \varepsilon_0\varepsilon_r\vec{E} = \varepsilon\vec{E}D=ε0​εr​E=εE

其中 εr\varepsilon_rεr​ 是相对介电常数，ε=ε0εr\varepsilon = \varepsilon_0\varepsilon_rε=ε0​εr​ 是介电常数。

介质中的高斯定理

∮SD⃗⋅dS⃗=∑q自由\oint_S \vec{D} \cdot d\vec{S} = \sum q_{\text{自由}}∮S​D⋅dS=∑q自由​

通过闭合曲面的 D⃗\vec{D}D 通量 = 曲面内自由电荷的代数和。

注意：介质中的高斯定理积分的是 D⃗\vec{D}D 而不是 E⃗\vec{E}E！DDD 的通量只取决于自由电荷。

5.6 有介质存在时的电场

5.6.1 基本公式

存在两种介质的界面时，边界条件：

  • DDD 的法向分量：D1n−D2n=σfD_{1n} - D_{2n} = \sigma_fD1n​−D2n​=σf​（自由电荷面密度）
    • 无自由电荷时：D1n=D2nD_{1n} = D_{2n}D1n​=D2n​
  • EEE 的切向分量：E1t=E2tE_{1t} = E_{2t}E1t​=E2t​（连续）

5.6.2 解题一般思路

介质存在时的电场求解步骤：

  1. 利用对称性写出 D⃗\vec{D}D 的分布
  2. 由 D=εED = \varepsilon ED=εE 求 E⃗\vec{E}E 的分布
  3. 由 EEE 求电势差和电容
  4. 检查边界条件是否满足

5.7 等效电容法

5.7.1 常见等效模型的推导

复杂电容网络的化简技巧：

  1. 识别串/并联关系：串联—电荷相同；并联—电压相同

  2. 对称性分析：利用电路的对称性简化

  3. Δ-Y 变换（星-三角变换）：

    注意：电容的 Δ-Y 与电阻互为对偶（电容串并联规则与电导相同）。

    Y→Δ（三个电容）： C12=C1C2C1+C2+C3C_{12} = \frac{C_1 C_2}{C_1 + C_2 + C_3}C12​=C1​+C2​+C3​C1​C2​​

    Δ→Y： C1=C12+C13+C12C13C23C_1 = C_{12} + C_{13} + \frac{C_{12}C_{13}}{C_{23}}C1​=C12​+C13​+C23​C12​C13​​ 或等价地：C1=C12C23+C23C31+C31C12C23C_1 = \dfrac{C_{12}C_{23} + C_{23}C_{31} + C_{31}C_{12}}{C_{23}}C1​=C23​C12​C23​+C23​C31​+C31​C12​​（循环对称）
