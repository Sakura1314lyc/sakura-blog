大学物理(A)I 考试常用二级结论速查：抛体45°最远、弹簧串并联、纯滚动加速度比、电容串并联、回旋周期与速度无关、楞次定律口诀等

二级结论是由基本公式一步推导得到的快捷结论，可在解题时直接使用，大幅提升效率。

一、质点运动学

抛体运动

二、质点动力学

牛顿定律应用

  • 轻绳：绳中张力处处相等（不计摩擦和绳质量）
  • 轻弹簧：两端弹力大小相等，方向相反
  • 分离条件：两物体间压力 N=0N = 0N=0（接触但无挤压）
  • 脱离轨道条件：轨道的支持力 N=0N = 0N=0（恰好离开轨道）
  • 绳松弛条件：绳中张力 T=0T = 0T=0（恰好绷直但无力）
  • 恰好完成竖直圆周运动条件（绳模型）：最高点 vmin⁡=gRv_{\min} = \sqrt{gR}vmin​=gR​
  • 恰好过最高点条件（杆模型）：最高点 vmin⁡=0v_{\min} = 0vmin​=0（杆可以推）

非惯性系

  • 在非惯性系中分析平衡问题，引入惯性力即可当惯性系处理
  • 匀速转动参考系中静止物体：加入惯性离心力 mω2rm\omega^2 rmω2r 后力平衡
  • 在转动系中运动的物体：还需加入 科里奥利力 −2mω⃗×v⃗相-2m\vec{\omega} \times \vec{v}_{\text{相}}−2mω×v相​

动量

  • 动量守恒判断：合外力为零 → 动量守恒；某一方向合力为零 → 该方向动量守恒
  • 完全弹性碰撞（一维，对心）：碰撞前后相对速度大小不变，方向相反：v1−v2=−(v1′−v2′)v_1 - v_2 = -(v_1' - v_2')v1​−v2​=−(v1′​−v2′​)
  • 质量相等的两球弹性碰撞后交换速度
  • 完全非弹性碰撞能量损失最大

变质量

  • 火箭方程（无重力）：v=v0+uln⁡m0mv = v_0 + u\ln\frac{m_0}{m}v=v0​+ulnmm0​​（uuu 为喷气相对速度）

势能与功

  • 弹性势能零点默认取原长处

角动量

  • 有心力   ⟹  \implies⟹ 对力心的角动量守恒   ⟹  \implies⟹ 平面运动
  • 掠面速度为常数：dAdt=L2m\frac{dA}{dt} = \frac{L}{2m}dtdA​=2mL​（开普勒第二定律的物理本质）

  • 固有长度（原长）：物体在静止的参考系中测量的长度 →\to→ 最长

五、静电场

电场强度

  • 均匀带电球面内部 E=0E = 0E=0（类似均匀球壳内部重力为零）
  • 无限大均匀带电平面的电场与距离无关（E=σ/2ε0E = \sigma/2\varepsilon_0E=σ/2ε0​ 处处相等）
  • 两无限大带电平面之间：同号叠加为零，异号叠加为 E=σ/ε0E = \sigma/\varepsilon_0E=σ/ε0​（平行板电容器内部）
  • 均匀带电圆环圆心处 E=0E = 0E=0（对称性抵消）

电势

  • 均匀带电球面内部电势等于表面电势：V=q/4πε0RV = q/4\pi\varepsilon_0 RV=q/4πε0​R（内部等势）
  • 无限大带电平面不能以无穷远为电势零点（积分发散）
  • 两等量异号点电荷中垂面是零电势面

导体

  • 导体表面场强：E=σ/ε0E = \sigma/\varepsilon_0E=σ/ε0​（带电导体表面外侧）
  • 尖端处曲率半径小 → 面电荷密度大 → 电场强 → 容易放电（尖端效应）
  • 导体内部场强为零，导体是等势体（静电平衡条件）
  • 空腔导体屏蔽外电场；接地空腔屏蔽内外互不影响

  • 电容并联等效值等于各分电容之和，C总=∑CiC_{\text{总}} = \sum C_iC总​=∑Ci​
  • 电容器串联时各电容电荷量相同；并联时各电容电压相同

  • 远处场强 ∝1/r3\propto 1/r^3∝1/r3（衰减比点电荷的 1/r21/r^21/r2 快）

  • 电容器充电后断开电源→ QQQ 不变，CCC 变则 VVV、WWW 变
  • 电容器始终接电源→ VVV 不变，CCC 变则 QQQ、WWW 变

八、电磁感应

楞次定律

  • 增反减同：磁通增大 → 感应电流产生反向磁场；磁通减小 → 感应电流产生同向磁场
  • 来拒去留：磁铁靠近线圈受排斥，远离线圈受吸引

动生电动势

  • 导线切割磁力线：E=Blv\mathcal{E} = BlvE=Blv（v⊥B⊥lv \perp B \perp lv⊥B⊥l）
  • 动生电动势的非静电力 = 洛伦兹力
  • 方向判断：右手定则——掌心朝向 NNN 极（BBB 方向），拇指为运动方向，四指为感应电流方向

感生电动势

  • 感生电动势的非静电力 = 涡旋电场力
  • 涡旋电场与静电场不同：电场线是闭合曲线（有旋无源）

自感与互感

  • 电感中电流不能突变：IL(0+)=IL(0−)I_L(0^+) = I_L(0^-)IL​(0+)=IL​(0−)（与电容电压不能突变对照）
  • RLRLRL 电路时间常数：τ=L/R\tau = L/Rτ=L/R
  • 自感电动势 EL=−LdIdt\mathcal{E}_L = -L\frac{dI}{dt}EL​=−LdtdI​ 总是阻碍电流变化
  • 两个线圈互感系数相等：M12=M21M_{12} = M_{21}M12​=M21​

磁场能量

  • 磁场能量密度形式与电场能量密度对称： we=12εE2  ⟷  wm=B22μw_e = \frac{1}{2}\varepsilon E^2 \;\longleftrightarrow\; w_m = \frac{B^2}{2\mu}we​=21​εE2⟷wm​=2μB2​

位移电流

  • 位移电流不是真实电流（无电荷流动），但在产生磁场这一点上与传导电流等价
  • 电容器充放电时，两极板间的位移电流”接续”了导线中的传导电流，保证全电流连续

麦克斯韦方程组

  • 四个方程描摹了完整的电磁场规律：电荷生电场、无磁单极、变磁生电、变电生磁
  • 变化的电场和变化的磁场互相激发，形成电磁波

电磁感应快速判据

  • 动生方向：右手定则——掌心向 N（B 方向），拇指指向 v，四指为 ε 方向
  • 感生方向：楞次定律——增反减同，来拒去留
