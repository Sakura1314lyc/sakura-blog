什么是区间 DP？

区间 DP 是在区间上做动态规划。其核心特征可以概括为：

  • 状态是区间：dp[l][r]dp[l][r]dp[l][r] 表示区间 [l,r][l, r][l,r] 上的最优解
  • 转移是合并：大区间由两个（或多个）小区间合并而来
  • 枚举分割点：在 lll 和 rrr 之间枚举分界点 kkk，将 [l,r][l, r][l,r] 拆分为 [l,k][l, k][l,k] 和 [k+1,r][k+1, r][k+1,r]

通用框架

// 区间 DP 通用骨架
for (int len = 2; len <= n; len++)             // ① 枚举区间长度
    for (int l = 1; l + len - 1 <= n; l++) {   // ② 枚举左端点
        int r = l + len - 1;                   //    计算右端点
        for (int k = l; k < r; k++)            // ③ 枚举分割点
            dp[l][r] = opt(dp[l][r],            //    合并两个子区间
                           dp[l][k] + dp[k + 1][r] + cost(l, r));
    }

时间复杂度：O(n3)O(n^3)O(n3)（三重循环），空间 O(n2)O(n^2)O(n2)。

为什么按长度枚举？

区间 DP 要求计算大区间时，所有子区间已求解。按长度从小到大枚举，自然满足这个顺序。这是区间 DP 与线性 DP 最大的实现差异。

一、石子合并 ——区间 DP 的「Hello World」

问题描述

nnn 堆石子排成一排，第 iii 堆有 aia_iai​ 个。每次合并相邻两堆，代价为两堆石子数之和。求将所有石子合并成一堆的最小代价。

状态与转移

  • dp[l][r]dp[l][r]dp[l][r]：合并区间 [l,r][l, r][l,r] 内所有石子所需的最小代价
  • 枚举最后一次合并的位置 kkk：
dp[l][r]=min⁡l≤k<r(dp[l][k]+dp[k+1][r])+∑i=lraidp[l][r] = \min_{l \le k < r} \big( dp[l][k] + dp[k+1][r] \big) + \sum_{i=l}^{r} a_idp[l][r]=l≤k<rmin​(dp[l][k]+dp[k+1][r])+i=l∑r​ai​

其中 ∑i=lrai\sum_{i=l}^{r} a_i∑i=lr​ai​ 可以用前缀和 O(1)O(1)O(1) 计算。

代码实现

// 石子合并（线性版本）
int solve(vector<int>& a) {
    int n = a.size();
    vector<int> pre(n + 1, 0);                 // 前缀和
    for (int i = 1; i <= n; i++)
        pre[i] = pre[i - 1] + a[i - 1];

    auto sum = [&](int l, int r) { return pre[r] - pre[l - 1]; };

    vector<vector<int>> dp(n + 2, vector<int>(n + 2, INT_MAX));
    for (int i = 1; i <= n; i++)
        dp[i][i] = 0;                          // 单堆不需要合并

    for (int len = 2; len <= n; len++)
        for (int l = 1; l + len - 1 <= n; l++) {
            int r = l + len - 1;
            for (int k = l; k < r; k++)
                dp[l][r] = min(dp[l][r],
                               dp[l][k] + dp[k + 1][r] + sum(l, r));
        }
    return dp[1][n];
}

环形石子合并

如果石子排成环，经典技巧：破环成链。将数组复制一份接在后面（长度变为 2n2n2n），然后分别求每个长度为 nnn 的区间的答案，取最值。

// 环形：复制数组
vector<int> a2(2 * n);
for (int i = 0; i < n; i++) {
    a2[i] = a2[i + n] = a[i];
}
// 对 a2 做区间 DP，答案 = min(dp[1][n], dp[2][n+1], ..., dp[n][2n-1])
int ans = INT_MAX;
for (int i = 1; i <= n; i++)
    ans = min(ans, dp[i][i + n - 1]);

戳气球

dp[l][r]dp[l][r]dp[l][r]：戳破区间 (l,r)(l, r)(l,r) 内所有气球（不含 lll 和 rrr）能获得的最大硬币数。

dp[l][r]=max⁡l<k<r(dp[l][k]+dp[k][r]+nums[l]⋅nums[k]⋅nums[r])dp[l][r] = \max_{l < k < r} \big( dp[l][k] + dp[k][r] + nums[l] \cdot nums[k] \cdot nums[r] \big)dp[l][r]=l<k<rmax​(dp[l][k]+dp[k][r]+nums[l]⋅nums[k]⋅nums[r])

这是区间 DP 的经典「开区间」模型——lll 和 rrr 是边界，不被戳破。

// LC 312. Burst Balloons
int maxCoins(vector<int>& nums) {
    int n = nums.size();
    vector<int> val(n + 2, 1);                 // 两端补齐虚拟气球
    for (int i = 0; i < n; i++) val[i + 1] = nums[i];
    vector<vector<int>> dp(n + 2, vector<int>(n + 2, 0));
    for (int len = 3; len <= n + 2; len++)     // len 从 3 开始(至少包含一个气球)
        for (int l = 0; l + len - 1 <= n + 1; l++) {
            int r = l + len - 1;
            for (int k = l + 1; k < r; k++)    // k 是最后一个被戳破的
                dp[l][r] = max(dp[l][r],
                               dp[l][k] + dp[k][r] + val[l] * val[k] * val[r]);
        }
    return dp[0][n + 1];
}

六、四边形不等式优化

当区间 DP 的代价函数 cost(l,r)cost(l, r)cost(l,r) 满足四边形不等式时，可以将复杂度从 O(n3)O(n^3)O(n3) 优化到 O(n2)O(n^2)O(n2)。

四边形不等式

对于任意 a≤b≤c≤da \le b \le c \le da≤b≤c≤d：

cost(a,c)+cost(b,d)≤cost(a,d)+cost(b,c)cost(a, c) + cost(b, d) \le cost(a, d) + cost(b, c)cost(a,c)+cost(b,d)≤cost(a,d)+cost(b,c)

直观理解：「交叉」和 ≤\le≤「包含」和。

决策单调性

若 costcostcost 满足四边形不等式，则最优分割点 kopt[l][r]k_{opt}[l][r]kopt​[l][r] 满足：

kopt[l][r−1]≤kopt[l][r]≤kopt[l+1][r]k_{opt}[l][r-1] \le k_{opt}[l][r] \le k_{opt}[l+1][r]kopt​[l][r−1]≤kopt​[l][r]≤kopt​[l+1][r]

这意味着我们不需要枚举所有 kkk，只需在 [kopt[l][r−1],kopt[l+1][r]][k_{opt}[l][r-1], k_{opt}[l+1][r]][kopt​[l][r−1],kopt​[l+1][r]] 这个小区间内搜索。

// 用 opt[l][r] 记录最优分割点
vector<vector<int>> opt(n + 2, vector<int>(n + 2));

for (int i = 1; i <= n; i++) {
    dp[i][i] = 0;
    opt[i][i] = i;                             // 初始化
}

for (int len = 2; len <= n; len++)
    for (int l = 1; l + len - 1 <= n; l++) {
        int r = l + len - 1;
        int kl = opt[l][r - 1];                // 搜索下界
        int kr = opt[l + 1][r];                // 搜索上界
        dp[l][r] = INT_MAX;
        for (int k = kl; k <= kr; k++) {
            int val = dp[l][k] + dp[k + 1][r] + sum(l, r);
            if (val < dp[l][r]) {
                dp[l][r] = val;
                opt[l][r] = k;
            }
        }
    }

七、区间 DP 的两种转移模型

区间 DP 普遍可以归为两类：

模型一：分裂型（divide and merge）

大区间由两个小区间分裂合并而来。枚举分割点 kkk：

dp[l][r]=optl≤k<r(dp[l][k]+dp[k+1][r]+cost)dp[l][r] = \mathop{\text{opt}}_{l \le k < r} \big( dp[l][k] + dp[k+1][r] + \text{cost} \big)dp[l][r]=optl≤k<r​(dp[l][k]+dp[k+1][r]+cost)

代表题目：石子合并、矩阵连乘、最优三角剖分（kkk 同时属于两边）。

模型二：扩边型（expand from edges）

大区间由小区间向两边各扩展一个元素（或一边）得来：

dp[l][r]=opt{dp[l+1][r]+cost from ldp[l][r−1]+cost from rdp[l+1][r−1]+cost from bothdp[l][r] = \mathop{\text{opt}}\begin{cases} dp[l+1][r] + \text{cost from }l\\ dp[l][r-1] + \text{cost from }r\\ dp[l+1][r-1] + \text{cost from both} \end{cases}dp[l][r]=opt⎩⎨⎧​dp[l+1][r]+cost from ldp[l][r−1]+cost from rdp[l+1][r−1]+cost from both​

代表题目：最长回文子序列、括号序列。

这种模型的循环方式也可以用区间长度，但转移中不需要枚举 kkk，时间复杂度 O(n2)O(n^2)O(n2)。

如何判断用哪种模型？

  • 问题问「合并」「拆分」→ 分裂型，枚举 kkk
  • 问题问「添加」「删除」「匹配两端字符」→ 扩边型，O(n2)O(n^2)O(n2)
  • 戳气球表面是分裂型，但 kkk 是最后被戳破的→特殊变体

总结

  1. 区间 DP 的灵魂是「区间长度从小到大」的枚举顺序，保证子问题先被求解
  2. 核心是识别分裂型还是扩边型——这决定了是否需要枚举分割点 kkk
  3. 环形问题用破环成链（数组复制一倍），是最常用的区间 DP 技巧
  4. 四边形不等式优化能将部分分裂型区间 DP 从 O(n3)O(n^3)O(n3) 降到 O(n2)O(n^2)O(n2)
