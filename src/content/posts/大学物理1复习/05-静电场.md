## 5.1 电场强度

### 5.1.1 基本公式

#### 库仑定律

点电荷 $q$ 对试探电荷 $q_0$ 的作用力：

$$\vec{F} = \frac{1}{4\pi\varepsilon_0}\frac{qq_0}{r^2}\hat{r}$$

其中 $\varepsilon_0 = 8.85 \times 10^{-12}\,\text{C}^2/\text{N}\!\cdot\!\text{m}^2$ 为真空介电常数。

#### 电场强度

$$\vec{E} = \frac{\vec{F}}{q_0}$$

- 点电荷的电场：$\vec{E} = \frac{1}{4\pi\varepsilon_0}\frac{q}{r^2}\hat{r}$
- 电场叠加原理：$\vec{E} = \sum \vec{E}_i$

#### 常见带电体的电场（重要结论）

| 带电体 | 场强 |
|--------|------|
| 点电荷 | $E = \frac{q}{4\pi\varepsilon_0 r^2}$ |
| 无限长均匀带电直线（线密度 $\lambda$） | $E = \frac{\lambda}{2\pi\varepsilon_0 r}$ |
| 无限大均匀带电平面（面密度 $\sigma$） | $E = \frac{\sigma}{2\varepsilon_0}$ |
| 均匀带电圆环轴线上（距环心 $x$） | $E = \frac{qx}{4\pi\varepsilon_0(x^2 + R^2)^{3/2}}$ |

#### 电偶极子

电偶极矩：$\vec{p} = q\vec{l}$（方向从 $-q$ 指向 $+q$）

- 在均匀外电场 $\vec{E}$ 中受力矩：$\vec{M} = \vec{p} \times \vec{E}$
- 电势能：$U = -\vec{p} \cdot \vec{E}$

#### 高斯定理

$$\oint_S \vec{E} \cdot d\vec{S} = \frac{1}{\varepsilon_0}\sum q_{\text{内}}$$

即通过任意闭合曲面的电通量 = 曲面内总电荷的 $1/\varepsilon_0$ 倍。

**应用高斯定理求电场的条件**：电场分布具有高度对称性（球对称、轴对称、平面对称）。

### 5.1.2 经典模型

#### 均匀带电球面/球体

- **球面**（半径 $R$）：$r < R$ 时 $E = 0$；$r > R$ 时 $E = \frac{q}{4\pi\varepsilon_0 r^2}$（相当于电荷集中在球心）
- **球体**（均匀带电）：$r < R$ 时 $E = \frac{qr}{4\pi\varepsilon_0 R^3}$（线性增加）；$r > R$ 时同上

#### 带电圆环/圆盘轴线上的电场

叠加法：将连续带电体分割为微元电荷 $dq$，写出 $dE$，积分得总电场。

## 5.2 电势

### 5.2.1 基本公式

#### 电势能与电势

- 电势能差：$U_b - U_a = -q\int_a^b \vec{E} \cdot d\vec{l}$（电场力做的功的负值）
- 电势（电位）：$V_a = \frac{U_a}{q}$
- 电势差（电压）：$V_a - V_b = \int_a^b \vec{E} \cdot d\vec{l}$

#### 点电荷的电势

以无穷远处为零电势点：
$$V = \frac{q}{4\pi\varepsilon_0 r}$$

- 正电荷：$V > 0$；负电荷：$V < 0$
- 电势叠加原理：$V = \sum V_i$

#### 电场与电势的关系

- 电场是电势的负梯度：$\vec{E} = -\nabla V$
- 一维：$E_x = -\frac{dV}{dx}$
- 等势面处处与电场线垂直
- 已知电势分布求电场：$\vec{E} = -\left(\frac{\partial V}{\partial x}\hat{i} + \frac{\partial V}{\partial y}\hat{j} + \frac{\partial V}{\partial z}\hat{k}\right)$

### 5.2.2 经典模型

#### 均匀带电球面的电势

- $r \ge R$：$V = \frac{q}{4\pi\varepsilon_0 r}$（与点电荷相同）
- $r < R$：$V = \frac{q}{4\pi\varepsilon_0 R}$（球面内部等电势）

#### 由电场分布求电势

已知 $E(r)$，取无穷远为电势零点：
$$V(r) = \int_r^\infty E(r)\,dr$$

## 5.3 导体的静电平衡

### 5.3.1 基本概念

**导体达到静电平衡的条件**：导体内部电场 $\vec{E} = 0$，表面 $\vec{E}$ 垂直于表面。

**静电平衡下导体的性质**：
1. 导体内部 $E = 0$，导体是等势体
2. 电荷只分布在导体表面，内部无净电荷
3. 导体表面的场强 $E = \frac{\sigma}{\varepsilon_0}$（$\sigma$ 为面电荷密度）
4. 表面曲率越大，面电荷密度越大（尖端效应）

**空腔导体**：
- 腔内无电荷时：内表面无电荷，腔内 $E = 0$
- 腔内有电荷时：内表面感应出等量异号电荷

### 5.3.2 经典模型

#### 接地导体板

接地 = 电势为零。大地可视为无限大的电荷源/汇。

#### 静电屏蔽

- 封闭导体空腔可以屏蔽外电场（腔内不受外电场影响）
- 接地的空腔可以同时对内外进行屏蔽（内外互不影响）

## 5.4 电容和电容器

### 5.4.1 基本公式

#### 电容的定义

$$C = \frac{Q}{V}$$

- 单位：法拉（F），$1\text{F} = 1\,\text{C}/\text{V}$
- 常用单位：$\mu\text{F}$（$10^{-6}$F）、$\text{pF}$（$10^{-12}$F）

#### 常见电容器的电容

| 电容器 | 电容公式 |
|--------|----------|
| 平行板电容器 | $C = \frac{\varepsilon_0 S}{d}$ |
| 圆柱形电容器（长 $L$） | $C = \frac{2\pi\varepsilon_0 L}{\ln(R_2/R_1)}$ |
| 球形电容器 | $C = \frac{4\pi\varepsilon_0 R_1 R_2}{R_2 - R_1}$ |
| 孤立导体球 | $C = 4\pi\varepsilon_0 R$ |

#### 电容器的串并联

- **串联**：$\frac{1}{C_{\text{总}}} = \frac{1}{C_1} + \frac{1}{C_2} + \cdots$（总电容减小，各电容电荷量相同）
- **并联**：$C_{\text{总}} = C_1 + C_2 + \cdots$（总电容增大，各电容电压相同）

#### 电容器的储能

$$W = \frac{1}{2}CV^2 = \frac{Q^2}{2C} = \frac{1}{2}QV$$

#### 电场的能量密度

$$w_e = \frac{1}{2}\varepsilon_0 E^2$$

总电场能：$W_e = \int w_e\,dV = \int \frac{1}{2}\varepsilon_0 E^2\,dV$

### 5.4.2 经典模型

#### 平行板电容器插入介质板

两块平行金属板间插入电介质板（相对介电常数 $\varepsilon_r$），电容等效为两个（或三个）电容器的串/并联。

## 5.5 电介质与高斯定理

### 5.5.1 基本公式

#### 电介质的极化

- **无极分子**：位移极化
- **有极分子**：取向极化

#### 极化强度与极化电荷

极化强度 $\vec{P}$（单位体积内的电偶极矩之和）。

极化电荷面密度：$\sigma' = P \cdot \hat{n}$（表面法向分量）

#### 电位移矢量

$$\vec{D} = \varepsilon_0\vec{E} + \vec{P}$$

对各向同性线性介质：$\vec{D} = \varepsilon_0\varepsilon_r\vec{E} = \varepsilon\vec{E}$

其中 $\varepsilon_r$ 是相对介电常数，$\varepsilon = \varepsilon_0\varepsilon_r$ 是介电常数。

#### 介质中的高斯定理

$$\oint_S \vec{D} \cdot d\vec{S} = \sum q_{\text{自由}}$$

通过闭合曲面的 $\vec{D}$ 通量 = 曲面内**自由电荷**的代数和。

> 注意：介质中的高斯定理积分的是 $\vec{D}$ 而不是 $\vec{E}$！$D$ 的通量只取决于自由电荷。

### 5.5.2 经典模型

#### 平行板间充满电介质

自由电荷面密度 $\sigma_0$，介质 $\varepsilon_r$：
$$D = \sigma_0,\quad E = \frac{\sigma_0}{\varepsilon_0\varepsilon_r} = \frac{E_0}{\varepsilon_r}$$

电容：$C = \varepsilon_r C_0$（增大为原来的 $\varepsilon_r$ 倍）

## 5.6 有介质存在时的电场

### 5.6.1 基本公式

存在两种介质的界面时，边界条件：

- **$D$ 的法向分量**：$D_{1n} - D_{2n} = \sigma_f$（自由电荷面密度）
  - 无自由电荷时：$D_{1n} = D_{2n}$
- **$E$ 的切向分量**：$E_{1t} = E_{2t}$（连续）

### 5.6.2 解题一般思路

介质存在时的电场求解步骤：
1. 利用对称性写出 $\vec{D}$ 的分布
2. 由 $D = \varepsilon E$ 求 $\vec{E}$ 的分布
3. 由 $E$ 求电势差和电容
4. 检查边界条件是否满足

## 5.7 等效电容法

### 5.7.1 常见等效模型的推导

复杂电容网络的化简技巧：

1. **识别串/并联关系**：串联—电荷相同；并联—电压相同
2. **对称性分析**：利用电路的对称性简化
3. **Δ-Y 变换**（星-三角变换）：

   Y→Δ（三个电容）：
   $$C_{12} = \frac{C_1 C_2}{C_1 + C_2 + C_3}$$

   Δ→Y：
   $$C_1 = \frac{C_{12}C_{31}}{C_{12} + C_{23} + C_{31}} + \text{（循环对称）}$$

## 5.8 电偶极子

### 5.8.1 基本公式

电偶极子：等量异号点电荷 $+q$、$-q$ 相距 $l$（很小）。

电偶极矩：$\vec{p} = q\vec{l}$

在电偶极子远处（$r \gg l$）的电场：
- 中垂线上：$\vec{E} \approx -\frac{1}{4\pi\varepsilon_0}\frac{\vec{p}}{r^3}$
- 延长线上：$\vec{E} \approx \frac{1}{4\pi\varepsilon_0}\frac{2\vec{p}}{r^3}$

电偶极子在均匀外电场中的势能：$U = -\vec{p} \cdot \vec{E}$

非均匀电场中电偶极子还受到净力：$\vec{F} = (\vec{p} \cdot \nabla)\vec{E}$

### 5.8.2 经典模型

电偶极子的电势：$V = \frac{1}{4\pi\varepsilon_0}\frac{p\cos\theta}{r^2}$

## 核心提醒

- 高斯定理的使用条件：$\vec{E}$ 在闭合面上大小一定且方向与面元平行/垂直
- 导体达到静电平衡时内部 $E = 0$
- $\vec{D}$ 的通量只由**自由电荷**决定，极化电荷不影响 $D$
- $C = \varepsilon_r C_0$：电介质使电容增大
- 电场能量密度：$w_e = \frac{1}{2}DE = \frac{1}{2}\varepsilon E^2$
