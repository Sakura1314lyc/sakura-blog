## 2.1 牛顿第二定律

### 2.1.1 基本公式

**牛顿三定律**：

1. **惯性定律**：不受力时物体保持静止或匀速直线运动
2. **运动定律**：$\vec{F} = m\vec{a} = m\frac{d\vec{v}}{dt} = m\frac{d^2\vec{r}}{dt^2}$
3. **作用-反作用定律**：$\vec{F}_{AB} = -\vec{F}_{BA}$

### 2.1.2 一般解题步骤

1. **选对象**：选取研究对象（取微元时取某时刻或某一微元）
2. **分析力**：分析对象的受力情况（主动力 + 约束反力）
3. **写方程**：
   - 自然坐标系：切向 $F_t = m\frac{dv}{dt}$，法向 $F_n = m\frac{v^2}{\rho}$
   - 直角坐标系：$F_x = m\ddot{x},\; F_y = m\ddot{y}$
4. **做变换**：通过等量关系将等式转化为关于时间或位置的微分方程
5. **求积分**：注意积分上下限

> **注意事项**：
> - 积分时必须注意上下限（初始条件与目标状态）
> - 若积分困难，考虑转换为微分方程
> - 绳中张力可以瞬时变化，绳突然绷紧/松弛时张力瞬时改变
> - 微元选择（弧微分等）时注意等价无穷小替换
> - **高阶无穷小在微元分析中可以直接省略**

### 2.1.3 经典模型

#### 模型一：抛体在阻力中的运动

**模型特征**：抛体运动 + 空气阻力 $f = -kv$（与速度成正比）。

在 $x$ 和 $y$ 方向分别列牛顿第二定律：
- $x$ 方向：$m\ddot{x} = -k\dot{x}$
- $y$ 方向：$m\ddot{y} = -k\dot{y} - mg$

分别积分得到速度函数，再积分得到位置函数。消去 $t$ 可得轨迹方程。

#### 模型二：小球在圆形轨道上的运动

**（1）轨道固定模型**

小球沿固定圆形轨道运动。列自然坐标系下的方程：
- 法向：$N - mg\cos\theta = m\frac{v^2}{R}$
- 切向：$-mg\sin\theta = m\frac{dv}{dt}$（摩擦力不计时）

当 $N = 0$ 时小球脱离轨道。

**（2）轨道不固定模型**

轨道（如滑块）不固定，需要：
- 对小球的法向方程
- 对滑块的水平方向方程
- 水平方向动量守恒
- 系统机械能守恒

联立四个方程求解。

#### 模型三：绳子连接体模型

**模型特征**：两物体通过绳子连接，绳子不可伸长。

以竖直向上的绳子方向为正，在绳上取极小一微元，分别对微元两端和整体列牛顿第二定律，联立得到加速度。绳中张力处处相等（轻绳、无摩擦时）。

#### 模型四：变质量物体模型

**（1）落链问题** — 链条一端从桌边落下

- 落下的部分受重力
- 整条链条一起加速（链条不可伸长）
- 列方程后积分可得速度随落下长度的关系

**（2）火箭问题** — 靠喷射燃料获得推力

取向上为正，设 $t$ 时刻火箭质量 $m$、速度 $v$：
- $dt$ 时间内喷出燃料质量为 $dm_f$，相对火箭喷出速度为 $u$
- 由动量定理得：$m\frac{dv}{dt} = -u\frac{dm}{dt} - mg$

积分可得**齐奥尔科夫斯基公式**：
$$v = v_0 + u\ln\frac{m_0}{m} - gt$$

当无重力时（如太空）：$v = u\ln\frac{m_0}{m}$

**（3）落雨模型** — 雨滴下落过程中不断吸收水汽

取向下为正，设 $t$ 时刻雨滴质量 $m$、速度 $v$，时间 $dt$ 内吸收质量 $dm$：
$$\frac{d(mv)}{dt} = mg$$

## 2.2 非惯性系中的动力学问题

### 2.2.1 匀速平动非惯性系中的惯性力

在相对惯性系以加速度 $\vec{a}_{\text{牵}}$ 平动的非惯性系中：

$$\vec{a}_{\text{相对}} = \vec{a}_{\text{绝对}} - \vec{a}_{\text{牵}}$$

**惯性力**：$\vec{F}_{\text{惯}} = -m\vec{a}_{\text{牵}}$

在非惯性系中牛顿第二定律的形式：
$$\vec{F} + \vec{F}_{\text{惯}} = m\vec{a}_{\text{相对}}$$

> 惯性力没有反作用力，不是真正的力，但在非惯性系中观察者"感受"得到。

### 2.2.2 匀速转动非惯性系中的惯性力

**（1）物体在转动系中静止**

在惯性系 $S$ 中，物体做匀速圆周运动：
$$f_{\text{摩擦}} = m\omega^2 r$$

在转动系 $S'$ 中，物体静止。引入**惯性离心力**：
$$\vec{F}_{\text{离心}} = m\omega^2 r\;\hat{r}$$

平衡条件：$\vec{f}_{\text{摩擦}} + \vec{F}_{\text{离心}} = 0$

**（2）物体在转动系中运动**

还需要引入**科里奥利力**（Coriolis force）：
$$\vec{F}_{\text{科}} = -2m\,\vec{\omega} \times \vec{v}_{\text{相对}}$$

总结：在转动参考系中
$$m\vec{a}_{\text{相对}} = \vec{F}_{\text{真实}} + \vec{F}_{\text{离心}} + \vec{F}_{\text{科}}$$

## 2.3 动量与动能

### 2.3.1 基本公式

#### 动量与冲量

- **动量**：$\vec{p} = m\vec{v}$
- **冲量**（力对时间的累积）：$\vec{I} = \int_{t_1}^{t_2} \vec{F}\,dt$
- **动量定理**：$\vec{I} = \Delta \vec{p} = \vec{p}_2 - \vec{p}_1$（末动量 − 初动量）
- **动量守恒定律**：系统所受合外力为零时，总动量守恒
  $$\sum \vec{p}_i = \text{常矢量}$$

#### 动能与功

- **功**（力对空间的累积）：$W = \int_a^b \vec{F} \cdot d\vec{r}$
- **动能**：$E_k = \frac{1}{2}mv^2$
- **动能定理**：$W_{\text{总}} = \Delta E_k$（末动能 − 初动能）

#### 保守力与势能

- **保守力**：做功与路径无关的力（如重力、弹力、万有引力、静电力）
- **势能**：
  - 重力势能：$E_p = mgh$（以 $h=0$ 为零势能面）
  - 弹性势能：$E_p = \frac{1}{2}kx^2$（以原长为零势能点）
  - 万有引力势能：$E_p = -G\frac{Mm}{r}$（以无穷远为零势能点）
- **保守力与势能的关系**：$\vec{F} = -\nabla E_p$

#### 机械能守恒定律

条件：系统只有保守力做功（非保守力不做功）

$$E_k + E_p = \text{常数}$$

即：$\frac{1}{2}mv^2 + E_p = \text{const}$

#### 功能原理

$$W_{\text{非保守}} = \Delta E_{\text{机械}}$$

非保守力做的功 = 机械能的增量。

### 2.3.2 经典模型

#### 模型一：弹簧谐振子

**模型特征**：弹簧一端固定，另一端连接质量为 $m$ 的物体，不计摩擦。

由牛顿第二定律：$-kx = m\ddot{x}$

即：$\ddot{x} + \frac{k}{m}x = 0$

令 $\omega = \sqrt{k/m}$，通解：$x = A\cos(\omega t + \varphi)$

- 周期：$T = \frac{2\pi}{\omega} = 2\pi\sqrt{\frac{m}{k}}$
- 频率：$f = \frac{1}{T} = \frac{1}{2\pi}\sqrt{\frac{k}{m}}$
- 最大速度：$v_{\max} = \omega A$

#### 模型二：平衡位置为原点的弹簧谐振

**模型特征**：弹簧竖直悬挂物体，以平衡位置为原点。

在平衡位置：$mg = kx_0$

以平衡位置为原点 $O$，取 $x$ 向下为正：
$$-k(x + x_0) + mg = m\ddot{x}$$

代入 $mg = kx_0$ 得：$-kx = m\ddot{x}$，即 $\ddot{x} + \omega^2 x = 0$

结论：以平衡位置为原点，弹簧振动仍为简谐运动，$\omega = \sqrt{k/m}$。

#### 模型三：绳子牵引（变力做功）

**模型特征**：通过绳子拉动水平面上的物体，拉力方向随物体运动改变。

- 解法一：动能定理。由水平方向动量守恒和机械能守恒联立。
- 解法二：从**能量角度**分析，拉力做的功等于物体动能的增量。

#### 模型四：绳子下摆（竖直圆周）

**模型特征**：小球从最低点以初速度沿绳子做圆周运动。

- 水平方向动量守恒
- 机械能守恒
- 物体做完整圆周运动的条件：最高点处绳子张力 $T \ge 0$

## 2.4 保守力与势能 · 运动微分方程

### 2.4.1 基本公式

#### 保守力与势能的关系

一维情况：$F(x) = -\frac{dE_p}{dx}$

三维情况：$\vec{F} = -\nabla E_p = -\left(\frac{\partial E_p}{\partial x}\hat{i} + \frac{\partial E_p}{\partial y}\hat{j} + \frac{\partial E_p}{\partial z}\hat{k}\right)$

#### 由势能函数求运动

已知势能函数 $E_p(x)$，由能量守恒：
$$\frac{1}{2}m\dot{x}^2 + E_p(x) = E_{\text{总}}$$

整理得：$\frac{dx}{dt} = \pm\sqrt{\frac{2}{m}(E_{\text{总}} - E_p(x))}$

分离变量积分可求运动时间。

### 2.4.2 经典模型

#### 势能曲线分析

- **平衡点**：$F = -\frac{dE_p}{dx} = 0$ → $E_p$ 取极值
  - 极小值点：**稳定平衡**（偏离后受回复力）
  - 极大值点：**不稳定平衡**（偏离后越来越远）
- **转折点**：$E_k = 0$ → $E_p(x) = E_{\text{总}}$，运动范围在此之内
- **束缚态**：能量不足以越过势垒，粒子在势阱中来回运动
- **非束缚态**：能量超过势垒，粒子可以运动到无穷远

## 2.5 质点与质点系的角动量定理

### 2.5.1 基本公式

- **角动量**（对定点 $O$）：$\vec{L} = \vec{r} \times \vec{p} = \vec{r} \times m\vec{v}$
  - 大小：$L = rmv\sin\theta = mrv_\perp$
- **力矩**（对定点 $O$）：$\vec{M} = \vec{r} \times \vec{F}$
  - 大小：$M = rF\sin\theta = rF_\perp$

- **角动量定理**：$\vec{M} = \frac{d\vec{L}}{dt}$
- **角动量守恒定律**：当对某点的合外力矩为零时，对该点的角动量守恒
  $$\vec{L} = \text{常矢量}$$

### 2.5.2 质点在有心力场中的运动

**有心力**：力始终指向（或背离）某一固定点（力心）。

- 对力心的力矩为零 → 对力心的**角动量守恒**
- 角动量守恒 → 质点做**平面运动**
- **掠面速度守恒**（开普勒第二定律）：$\frac{dA}{dt} = \frac{L}{2m} = \text{常数}$

万有引力提供向心力：
$$G\frac{Mm}{r^2} = m\frac{v^2}{r} = m\omega^2 r$$

轨道周期：$T^2 = \frac{4\pi^2}{GM}a^3$（开普勒第三定律，$a$ 为半长轴）

### 2.5.3 经典模型

#### 质点系的角动量守恒

当系统所受合外力矩为零时，系统总角动量守恒。典型问题：人从转台边缘走到中心，转台角速度增大（因为转动惯量减小）。
