## 一、质点运动学

### 抛体运动

- **$45^\circ$ 射程最远**：初速度 $v_0$ 一定时，仰角 $\theta = 45^\circ$ 时射程最大，$R_{\max} = v_0^2/g$
- **互余角射程相等**：$\theta$ 与 $90^\circ - \theta$ 的射程相同
- **最大高度时的速度**：$v_y = 0$，$v = v_x = v_0\cos\theta$（全程水平速度不变）
- **对称性**：上升时间 = 下降时间 = $v_0\sin\theta/g$；从同一高度出发和落回同一高度时，初末速率相等

### 关联速度

- 杆/绳不可伸长 $\implies$ **两端沿杆方向的速度分量相等**
- 接触面无滑动 $\implies$ **接触点处法向速度相等**
- 滑轮问题中绳不伸长 $\implies$ 绳两端加速度大小相等（方向由绕法决定）

### 相对运动

- 两物体加速度相等时，可将其一视为参考系，问题退化为伽利略变换
- 追及/相遇问题：相对速度 $v_{\text{相}} = v_B - v_A$，相对距离为 $d$ 时相遇时间 $t = d/v_{\text{相}}$

### 匀变速运动

- 等时间间隔位移差：$\Delta x = aT^2$（打点计时器核心公式）
- 中点速度 $>$ 中时速度（加速时）：$v_{x/2} > v_{t/2}$

## 二、质点动力学

### 牛顿定律应用

- **轻绳**：绳中张力处处相等（不计摩擦和绳质量）
- **轻弹簧**：两端弹力大小相等，方向相反
- **分离条件**：两物体间压力 $N = 0$（接触但无挤压）
- **脱离轨道条件**：轨道的支持力 $N = 0$（恰好离开轨道）
- **绳松弛条件**：绳中张力 $T = 0$（恰好绷直但无力）
- **恰好完成竖直圆周运动条件**（绳模型）：最高点 $v_{\min} = \sqrt{gR}$
- **恰好过最高点条件**（杆模型）：最高点 $v_{\min} = 0$（杆可以推）

### 非惯性系

- 在非惯性系中分析平衡问题，引入惯性力即可当惯性系处理
- 匀速转动参考系中静止物体：加入**惯性离心力** $m\omega^2 r$ 后力平衡
- 在转动系中运动的物体：还需加入 **科里奥利力** $-2m\vec{\omega} \times \vec{v}_{\text{相}}$

### 动量

- **动量守恒判断**：合外力为零 → 动量守恒；某一方向合力为零 → 该方向动量守恒
- **完全弹性碰撞**（一维，对心）：碰撞前后相对速度大小不变，方向相反：$v_1 - v_2 = -(v_1' - v_2')$
- **质量相等的两球**弹性碰撞后**交换速度**
- **完全非弹性碰撞**能量损失最大

### 变质量

- **火箭方程**（无重力）：$v = v_0 + u\ln\frac{m_0}{m}$（$u$ 为喷气相对速度）
- 落链/落雨问题：用动量定理的微分形式 $d(mv) = F\,dt$

### 势能与功

- **弹性势能零点默认取原长**处
- **弹簧串并联等效劲度系数**：
  - 串联（各弹簧受力相同）：$\frac{1}{k_{\text{eff}}} = \sum\frac{1}{k_i}$
  - 并联（各弹簧形变相同）：$k_{\text{eff}} = \sum k_i$
- 保守力做功 $W = -\Delta E_p$（与路径无关）

### 角动量

- 有心力 $\implies$ 对力心的**角动量守恒** $\implies$ 平面运动
- 掠面速度为常数：$\frac{dA}{dt} = \frac{L}{2m}$（开普勒第二定律的物理本质）

## 三、刚体力学

### 转动惯量

- 质量分布离轴越远，转动惯量越大
- 平行轴移轴 $+d$，转动惯量增加 $md^2$
- **实心球的转动惯量小于薄球壳**（质量更集中于中心）：$\frac{2}{5}mR^2 < \frac{2}{3}mR^2$

### 纯滚动的万能三方程

1. 平动：$mg\sin\theta - f = ma_C$（沿斜面方向）
2. 转动：$fR = I_C\alpha$（绕质心）
3. 约束：$a_C = R\alpha$（纯滚动条件）

三式联立，解得 $a_C = \frac{g\sin\theta}{1 + \frac{I_C}{mR^2}}$

### 纯滚动加速度对比

| 刚体 | $I_C/mR^2$ | 纯滚动下滑加速度 |
|:---|:---|:---|
| 圆环 | $1$ | $\frac{1}{2}g\sin\theta$ |
| 圆盘 | $\frac{1}{2}$ | $\frac{2}{3}g\sin\theta$ |
| 实心球 | $\frac{2}{5}$ | $\frac{5}{7}g\sin\theta$ |
| 质点（滑动） | $0$ | $g\sin\theta$ |

**质量分布越集中，滚得越快。** 实心球 > 圆盘 > 圆环 >（纯滑动无滚最快）。

### 刚体转动

- 定滑轮有质量时，两侧绳张力**不相等**（否则无力矩产生角加速度）
- 杆倒下着地时角速度：$\omega = \sqrt{\frac{3g}{L}}$（绕端点倒下）
- 陀螺进动方向：$\vec{\Omega}$ 使得 $\vec{L}$ 趋向 $\vec{M}$ 的方向（$\vec{M} = \vec{\Omega} \times \vec{L}$）

## 四、相对论基础

### 钟慢与尺缩

- **动钟变慢**（运动的钟走得慢）：$\Delta t = \gamma \Delta t_0 > \Delta t_0$
- **动尺变短**（运动的尺沿运动方向缩短）：$L = L_0/\gamma < L_0$
- 垂直运动方向的长度**不变**

### 判断"固有量"

- **固有时（原时）**：两个事件发生在**同一地点**的参考系中测量的时间 $\to$ 最短
- **固有长度（原长）**：物体在**静止**的参考系中测量的长度 $\to$ 最长

### 速度变换

- 低速近似下（$u \ll c$）退化为伽利略速度变换 $v'_x = v_x - u$
- 光速在任何参考系中都是 $c$：代入 $v = c$ 验证 $v' = c$

### 能量与动量

- 光子（$m_0 = 0$）：$E = pc$，无法静止
- 低速下相对论动能退化为经典动能：$E_k \approx \frac{1}{2}m_0v^2$（$v \ll c$ 时）
- 碰撞问题中**静止质量可以不守恒**（可转化为动能），但总能量和总动量守恒

## 五、静电场

### 电场强度

- 均匀带电球面内部 $E = 0$（类似均匀球壳内部重力为零）
- 无限大均匀带电平面的电场与距离**无关**（$E = \sigma/2\varepsilon_0$ 处处相等）
- 两无限大带电平面之间：同号叠加为零，异号叠加为 $E = \sigma/\varepsilon_0$（平行板电容器内部）
- 均匀带电圆环圆心处 $E = 0$（对称性抵消）

### 电势

- 均匀带电球面内部电势等于表面电势：$V = q/4\pi\varepsilon_0 R$（内部等势）
- 无限大带电平面不能以无穷远为电势零点（积分发散）
- 两等量异号点电荷中垂面是零电势面

### 导体

- 导体表面场强：$E = \sigma/\varepsilon_0$（带电导体表面外侧）
- 尖端处曲率半径小 → 面电荷密度大 → 电场强 → 容易放电（尖端效应）
- **导体内部场强为零**，**导体是等势体**（静电平衡条件）
- 空腔导体屏蔽外电场；**接地**空腔屏蔽内外互不影响

### 电容

- 插入电介质：$C = \varepsilon_r C_0$（电容增大 $\varepsilon_r$ 倍）
- **电容串联等效值小于任一分电容**，$C_{\text{总}} < \min(C_i)$
- **电容并联等效值等于各分电容之和**，$C_{\text{总}} = \sum C_i$
- 电容器串联时各电容**电荷量相同**；并联时各电容**电压相同**

### 电偶极子

- 远处场强 $\propto 1/r^3$（衰减比点电荷的 $1/r^2$ 快）
- 均匀电场中电偶极子：力矩使其**转向与电场平行**，势能 $U = -\vec{p}\cdot\vec{E}$
- 非均匀电场中电偶极子还受净力，被吸向电场强的区域

## 六、恒定电流

### RC 电路

- **时间常数** $\tau = RC$：经过 $\tau$ 后，充电完成 63%，放电剩余 37%
- 经过 $5\tau$ 基本达到稳态（充电 > 99%，放电 < 1%）
- **电容电压不能突变**：$V_C(0^+) = V_C(0^-)$
- 稳态时（$t \to \infty$）：电容等效为**断路**（$I_C = 0$）

### 基尔霍夫

- 列 KVL 时：**绕行方向与电流同向时，过电阻电压降取 $+IR$**
- 节点电流法：未知电流方向可以先任意假设，解出负号说明实际方向相反

### 电阻

- $n$ 个相同电阻 $R_0$ 串联：$R = nR_0$；并联：$R = R_0/n$
- 由于导线电阻过小，理想情况下导线等电势（不计电阻时）

## 七、磁场

### 磁场强度（$B$）

- 无限长直导线的磁场：$B = \frac{\mu_0 I}{2\pi r}$（$\propto 1/r$）
- 长直螺线管内部**均匀磁场**：$B = \mu_0 nI$；外部 $B \approx 0$
- 螺绕环内 $B = \frac{\mu_0 NI}{2\pi r}$（非均匀，随 $r$ 变化）

### 洛伦兹力

- **洛伦兹力不做功**（力始终垂直于速度），只改变方向，不改变速率
- 回旋（拉莫尔）频率 $\omega = qB/m$——**与速度大小无关**，只取决于比荷 $q/m$ 和磁场
- 回旋周期与速度无关是回旋加速器的理论基础

### 安培力

- 两平行载流导线：**同向电流相吸，反向电流相斥**
- 闭合载流线圈在均匀磁场中合力为零，但力矩不为零

### 霍尔效应

- 霍尔电压的正负号可以判断**载流子类型**（正电荷 vs 负电荷）
- 金属中载流子为电子（负电荷），$V_H$ 为负

### 磁介质

- 铁磁质中 $B$ 与 $H$ 有**磁滞**现象（非线性，有剩磁和矫顽力）
- 超导体是**完全抗磁体**（迈斯纳效应，$B_{\text{内}} = 0$）

## 八、电磁感应

### 楞次定律

- **增反减同**：磁通增大 → 感应电流产生反向磁场；磁通减小 → 感应电流产生同向磁场
- **来拒去留**：磁铁靠近线圈受排斥，远离线圈受吸引

### 动生电动势

- 导线切割磁力线：$\mathcal{E} = Blv$（$v \perp B \perp l$）
- 动生电动势的非静电力 = **洛伦兹力**
- 方向判断：**右手定则**——掌心朝向 $N$ 极（$B$ 方向），拇指为运动方向，四指为感应电流方向

### 感生电动势

- 感生电动势的非静电力 = **涡旋电场力**
- 涡旋电场与静电场不同：电场线是**闭合曲线**（有旋无源）

### 自感与互感

- **电感中电流不能突变**：$I_L(0^+) = I_L(0^-)$（与电容电压不能突变对照）
- $RL$ 电路时间常数：$\tau = L/R$
- 自感电动势 $\mathcal{E}_L = -L\frac{dI}{dt}$ 总是**阻碍电流变化**
- 两个线圈互感系数相等：$M_{12} = M_{21}$

### 磁场能量

- 磁场能量密度形式与电场能量密度对称：
  $$w_e = \frac{1}{2}\varepsilon E^2 \;\longleftrightarrow\; w_m = \frac{B^2}{2\mu}$$

### 位移电流

- 位移电流不是真实电流（无电荷流动），但**在产生磁场这一点上与传导电流等价**
- 电容器充放电时，两极板间的位移电流"接续"了导线中的传导电流，保证全电流连续

### 麦克斯韦方程组

- 四个方程描摹了完整的电磁场规律：电荷生电场、无磁单极、变磁生电、变电生磁
- 变化的电场和变化的磁场互相激发，形成电磁波

## 附录：快速判断口诀

| 场景 | 口诀 |
|:---|:---|
| 抛体 | 45° 最远，互余角等远 |
| 弹簧串并联 | 串软并硬（串联刚度减、并联刚度增） |
| 弹性碰撞 | 质量相等→交换速度 |
| 纯滚动加速度 | 越集中滚越快：球 > 盘 > 环 |
| 钟慢尺缩 | 动钟慢、动尺短、垂直不变 |
| 电容串并联 | 串联分压容量减，并联分流容量加 |
| 同反向电流 | 同向相吸，反向相斥 |
| 楞次定律 | 增反减同，来拒去留 |
| 动生方向 | 右手定则（掌心向 N，拇指 v，四指 I） |
| 暂态不突变 | 电容电压不突变，电感电流不突变 |
| RC/LR 时间常数 | $\tau_C = RC$（充放电），$\tau_L = L/R$（电流建立/衰减） |
