## 一、质点运动学

### 速度与加速度

$$\vec{v} = \frac{d\vec{r}}{dt},\quad \vec{a} = \frac{d\vec{v}}{dt} = \frac{d^2\vec{r}}{dt^2}$$

### 伽利略变换

$$\vec{v}_{\text{绝}} = \vec{v}_{\text{相}} + \vec{v}_{\text{牵}}$$

### 匀变速直线运动

$$v = v_0 + at$$
$$x = x_0 + v_0t + \frac{1}{2}at^2$$
$$v^2 - v_0^2 = 2a(x - x_0)$$

### 自然坐标系

$$a_t = \frac{dv}{dt},\quad a_n = \frac{v^2}{\rho}$$
$$a = \sqrt{a_t^2 + a_n^2}$$

### 抛体运动

$$x = v_0\cos\theta \cdot t,\quad y = v_0\sin\theta \cdot t - \frac{1}{2}gt^2$$
$$R = \frac{v_0^2\sin 2\theta}{g},\quad H = \frac{v_0^2\sin^2\theta}{2g}$$

### 极坐标系

$$v_r = \dot{r},\quad v_\theta = r\dot{\theta}$$
$$a_r = \ddot{r} - r\dot{\theta}^2,\quad a_\theta = r\ddot{\theta} + 2\dot{r}\dot{\theta}$$

## 二、质点动力学

### 牛顿第二定律

$$\vec{F} = m\vec{a} = m\frac{d\vec{v}}{dt}$$
自然坐标系：$F_t = m\frac{dv}{dt},\quad F_n = m\frac{v^2}{\rho}$

### 非惯性系

$$\vec{F}_{\text{惯}} = -m\vec{a}_{\text{牵}}$$
$$\vec{F}_{\text{离心}} = m\omega^2 r\,\hat{r},\quad \vec{F}_{\text{科}} = -2m\,\vec{\omega} \times \vec{v}_{\text{相}}$$

### 动量与冲量

$$\vec{p} = m\vec{v}$$
$$\vec{I} = \int_{t_1}^{t_2}\vec{F}\,dt = \Delta \vec{p}$$

**动量守恒**：合外力为零时 $\sum \vec{p}_i = \text{常矢量}$

### 功与动能

$$W = \int_a^b \vec{F} \cdot d\vec{r}$$
$$E_k = \frac{1}{2}mv^2$$
$$W_{\text{总}} = \Delta E_k$$

### 势能

重力：$E_p = mgh$
弹性：$E_p = \frac{1}{2}kx^2$
万有引力：$E_p = -G\frac{Mm}{r}$

保守力与势能：$\vec{F} = -\nabla E_p$

### 机械能守恒

条件：只有保守力做功。$E_k + E_p = \text{常数}$

### 角动量

$$\vec{L} = \vec{r} \times \vec{p},\quad \vec{M} = \vec{r} \times \vec{F}$$
$$\vec{M} = \frac{d\vec{L}}{dt}$$

**角动量守恒**：合外力矩为零时 $\vec{L} = \text{常矢量}$

## 三、刚体力学

### 转动惯量

$$I = \int r^2 dm$$

| 常见形状（绕质心轴） | $I$ |
|:---|:---|
| 细杆（长 $L$） | $\frac{1}{12}mL^2$ |
| 圆环（半径 $R$） | $mR^2$ |
| 圆盘（半径 $R$） | $\frac{1}{2}mR^2$ |
| 实心球（半径 $R$） | $\frac{2}{5}mR^2$ |
| 薄球壳（半径 $R$） | $\frac{2}{3}mR^2$ |

### 平行轴定理

$$I = I_C + md^2$$

### 垂直轴定理（薄板）

$$I_z = I_x + I_y$$

### 转动定律

$$\vec{M} = I\vec{\alpha}$$

### 转动动能

$$E_k = \frac{1}{2}I\omega^2$$

### 纯滚动条件

$$v_C = \omega R$$

### 刚体机械能守恒

$$\frac{1}{2}I\omega^2 + mgh_C = \text{常数}$$

### 进动角速度

$$\Omega = \frac{mgr}{I\omega}$$

## 四、相对论基础

### 洛伦兹因子

$$\gamma = \frac{1}{\sqrt{1 - u^2/c^2}}$$

### 洛伦兹变换（$S'$ 相对 $S$ 沿 $x$ 以 $u$ 运动）

$$x' = \gamma(x - ut),\quad t' = \gamma\left(t - \frac{u}{c^2}x\right)$$
$$x = \gamma(x' + ut'),\quad t = \gamma\left(t' + \frac{u}{c^2}x'\right)$$

### 速度变换

$$v'_x = \frac{v_x - u}{1 - \frac{uv_x}{c^2}},\quad v'_y = \frac{v_y}{\gamma(1 - \frac{uv_x}{c^2})}$$

### 时间延缓

$$\Delta t = \gamma\,\Delta t_0$$

### 长度收缩

$$L = \frac{L_0}{\gamma}$$

### 相对论动力学

$$m = \gamma_v m_0,\quad \vec{p} = \gamma_v m_0\vec{v}$$
$$E_k = (\gamma_v - 1)m_0c^2$$
$$E = mc^2 = \gamma_v m_0c^2$$
$$E^2 = p^2c^2 + m_0^2c^4$$

## 五、静电场

### 库仑定律

$$F = \frac{1}{4\pi\varepsilon_0}\frac{q_1q_2}{r^2},\quad \varepsilon_0 = 8.85 \times 10^{-12}\ \text{C}^2/\text{N}\!\cdot\!\text{m}^2$$

### 电场强度

$$\vec{E} = \frac{\vec{F}}{q_0}$$
点电荷：$E = \frac{q}{4\pi\varepsilon_0 r^2}$

### 高斯定理

$$\oint_S \vec{E} \cdot d\vec{S} = \frac{1}{\varepsilon_0}\sum q_{\text{内}}$$

### 常见场强结论

| 带电体 | $E$ |
|:---|:---|
| 点电荷 | $\frac{q}{4\pi\varepsilon_0 r^2}$ |
| 无限长带电直线 | $\frac{\lambda}{2\pi\varepsilon_0 r}$ |
| 无限大带电平面 | $\frac{\sigma}{2\varepsilon_0}$ |
| 均匀带电球面内 | $0$ |
| 螺线管（磁场类比位置） | — |

### 电势

$$V_a = \frac{U_a}{q},\quad V_a - V_b = \int_a^b \vec{E} \cdot d\vec{l}$$

点电荷：$V = \frac{q}{4\pi\varepsilon_0 r}$
$\vec{E} = -\nabla V$

### 电偶极子

$$\vec{p} = q\vec{l}$$
力矩：$\vec{M} = \vec{p} \times \vec{E}$
势能：$U = -\vec{p} \cdot \vec{E}$

### 电容

$$C = \frac{Q}{V}$$
平行板电容器：$C = \frac{\varepsilon_0 S}{d}$
孤立导体球：$C = 4\pi\varepsilon_0 R$

串联：$\frac{1}{C} = \sum\frac{1}{C_i}$；并联：$C = \sum C_i$

### 电场能量

电容储能：$W_e = \frac{1}{2}CV^2 = \frac{Q^2}{2C} = \frac{1}{2}QV$
能量密度：$w_e = \frac{1}{2}\varepsilon E^2 = \frac{1}{2}DE$

### 电介质

$$\vec{D} = \varepsilon_0\vec{E} + \vec{P} = \varepsilon_0\varepsilon_r\vec{E} = \varepsilon\vec{E}$$
介质中的高斯定理：$\oint_S \vec{D} \cdot d\vec{S} = \sum q_{\text{自由}}$

## 六、恒定电流

### 电流密度

$$\vec{J} = \sigma\vec{E},\quad I = \int_S \vec{J} \cdot d\vec{S}$$

### 电阻

$$R = \rho\frac{l}{S},\quad \rho = \frac{1}{\sigma}$$

### 欧姆定律

一段均匀电路：$V_a - V_b = IR$
含源：$V_a - V_b = IR - \mathcal{E}$（方向需判断）

### 电动势

$$\mathcal{E} = \int_{-}^{+} \vec{E}_k \cdot d\vec{l}$$

### 基尔霍夫定律

KCL：$\sum I_{\text{入}} = \sum I_{\text{出}}$
KVL：$\sum\mathcal{E} + \sum IR = 0$

### 焦耳定律

$$P = IV = I^2R = \frac{V^2}{R}$$

### RC 暂态

时间常数：$\tau = RC$
充电：$q = C\mathcal{E}(1 - e^{-t/RC})$
放电：$q = Q_0 e^{-t/RC}$

## 七、磁场

### 毕奥-萨伐尔定律

$$d\vec{B} = \frac{\mu_0}{4\pi}\frac{Id\vec{l} \times \hat{r}}{r^2},\quad \mu_0 = 4\pi \times 10^{-7}\ \text{T}\!\cdot\!\text{m}/\text{A}$$

### 常见磁场结论

| 电流分布 | $B$ |
|:---|:---|
| 无限长直导线（距 $r$） | $\frac{\mu_0 I}{2\pi r}$ |
| 圆电流圆心 | $\frac{\mu_0 I}{2R}$ |
| 圆电流轴线（距中心 $x$） | $\frac{\mu_0 IR^2}{2(x^2+R^2)^{3/2}}$ |
| 长直螺线管内部 | $\mu_0 nI$ |
| 一段直导线 | $\frac{\mu_0 I}{4\pi r}(\sin\theta_2 - \sin\theta_1)$ |

### 磁场高斯定理

$$\oint_S \vec{B} \cdot d\vec{S} = 0$$

### 安培环路定理

$$\oint_L \vec{B} \cdot d\vec{l} = \mu_0 \sum I_{\text{内}}$$

### 洛伦兹力

$$\vec{F} = q(\vec{E} + \vec{v} \times \vec{B})$$

带电粒子在均匀磁场中的圆周运动：
$$R = \frac{mv}{qB},\quad T = \frac{2\pi m}{qB},\quad \omega = \frac{qB}{m}$$

### 安培力

$$d\vec{F} = Id\vec{l} \times \vec{B}$$
均匀磁场中直导线：$F = BIL\sin\theta$

两平行载流导线单位长度受力：$f = \frac{\mu_0 I_1 I_2}{2\pi d}$

### 磁矩

$$\vec{m} = NI\vec{S}$$
力矩：$\vec{M} = \vec{m} \times \vec{B}$
势能：$U = -\vec{m} \cdot \vec{B}$

### 磁介质

$$\vec{H} = \frac{\vec{B}}{\mu_0} - \vec{M},\quad \vec{B} = \mu_0\mu_r\vec{H} = \mu\vec{H}$$
介质中安培环路定理：$\oint_L \vec{H} \cdot d\vec{l} = \sum I_{\text{自由}}$

### 霍尔效应

$$V_H = \frac{IB}{nqd}$$

## 八、电磁感应

### 法拉第定律

$$\mathcal{E} = -\frac{d\Phi_B}{dt},\quad \Phi_B = \int_S \vec{B} \cdot d\vec{S}$$

### 动生电动势

$$\mathcal{E} = \int (\vec{v} \times \vec{B}) \cdot d\vec{l}$$
均匀正交情况：$\mathcal{E} = Blv$

### 感生电动势（涡旋电场）

$$\oint \vec{E}_{\text{涡}} \cdot d\vec{l} = -\int_S \frac{\partial \vec{B}}{\partial t} \cdot d\vec{S}$$

### 自感

$$\Phi_B = LI,\quad \mathcal{E}_L = -L\frac{dI}{dt}$$
长直螺线管：$L = \frac{\mu_0 N^2 S}{l} = \mu_0 n^2 lS$

### 互感

$$\mathcal{E}_{21} = -M\frac{dI_1}{dt},\quad M_{12} = M_{21} = M$$

### 磁场能量

线圈储能：$W_m = \frac{1}{2}LI^2$
能量密度：$w_m = \frac{B^2}{2\mu} = \frac{1}{2}BH = \frac{1}{2}\mu H^2$

### 位移电流

$$I_d = \varepsilon_0\frac{d\Phi_E}{dt},\quad \vec{J}_d = \varepsilon_0\frac{\partial\vec{E}}{\partial t}$$

全电流安培定律：
$$\oint_L \vec{H} \cdot d\vec{l} = \sum I + \int_S \frac{\partial\vec{D}}{\partial t} \cdot d\vec{S}$$

### 麦克斯韦方程组（积分形式）

$$\oint_S \vec{D} \cdot d\vec{S} = \sum q$$
$$\oint_S \vec{B} \cdot d\vec{S} = 0$$
$$\oint_L \vec{E} \cdot d\vec{l} = -\int_S \frac{\partial \vec{B}}{\partial t} \cdot d\vec{S}$$
$$\oint_L \vec{H} \cdot d\vec{l} = \sum I + \int_S \frac{\partial \vec{D}}{\partial t} \cdot d\vec{S}$$
