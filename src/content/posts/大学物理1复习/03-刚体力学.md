## 3.1 转动惯量与转动定律

### 3.1.1 基本公式

#### 转动惯量

**定义**：$I = \sum m_i r_i^2$（离散）；$I = \int r^2\,dm$（连续）

**常见形状的转动惯量**（绕质心轴/对称轴）：

| 刚体 | 转轴 | 转动惯量 |
|------|------|----------|
| 细杆（长 $L$） | 过中点垂直杆 | $\frac{1}{12}mL^2$ |
| 细杆（长 $L$） | 过端点垂直杆 | $\frac{1}{3}mL^2$ |
| 圆环（半径 $R$） | 过圆心垂直环面 | $mR^2$ |
| 圆盘（半径 $R$） | 过圆心垂直盘面 | $\frac{1}{2}mR^2$ |
| 实心球（半径 $R$） | 过球心 | $\frac{2}{5}mR^2$ |
| 薄球壳（半径 $R$） | 过球心 | $\frac{2}{3}mR^2$ |

#### 平行轴定理

$$I = I_C + md^2$$

其中 $I_C$ 是对质心轴的转动惯量，$d$ 是两平行轴之间的距离。

#### 垂直轴定理（仅适用于薄板）

对薄板所在平面内的两个互相垂直的轴 $x$、$y$，和对与板面垂直的轴 $z$：

$$I_z = I_x + I_y$$

#### 转动定律

$$\vec{M} = I\vec{\alpha}$$

其中 $\vec{M}$ 是合外力矩，$\vec{\alpha} = \frac{d\vec{\omega}}{dt}$ 是角加速度。

- 力矩大小：$M = rF\sin\theta$（$\theta$ 为 $\vec{r}$ 与 $\vec{F}$ 的夹角）
- 力矩方向：右手螺旋定则

### 3.1.2 经典模型

#### 滑轮-重物系统

绳子绕在定滑轮上，一端挂重物。滑轮质量不可忽略时：

- 对重物：$mg - T = ma$
- 对滑轮：$TR = I\alpha$
- 运动学约束：$a = R\alpha$

联立三式解出 $a$、$T$、$\alpha$。

## 3.2 刚体转动中的功能关系

### 3.2.1 基本公式

#### 转动动能

$$E_k = \frac{1}{2}I\omega^2$$

#### 力矩的功

$$W = \int_{\theta_1}^{\theta_2} M\,d\theta$$

功率：$P = M\omega$

#### 刚体的动能定理

$$W_{\text{外力矩}} = \Delta E_k = \frac{1}{2}I\omega_2^2 - \frac{1}{2}I\omega_1^2$$

#### 刚体的重力势能

$$E_p = mgh_C$$

其中 $h_C$ 是质心的高度。刚体的重力势能 = 质量集中在质心时的重力势能。

#### 刚体的机械能守恒

若只有保守力（矩）做功，则：

$$\frac{1}{2}I\omega^2 + mgh_C = \text{常数}$$

### 3.2.2 经典模型

#### 杆从竖直位置倒下

均匀细杆长 $L$、质量 $m$，初始竖直站立，轻轻扰动后倒下。以杆下端为转轴，转动惯量 $I = \frac{1}{3}mL^2$。

由机械能守恒（初始质心高度 $L/2$）：
$$\frac{1}{2}I\omega^2 + mg\frac{L}{2}\cos\theta = mg\frac{L}{2}$$

可求出 $\omega(\theta)$，进而求杆着地时的角速度。

## 3.3 平面平行运动学

### 3.3.1 基本公式

**平面平行运动**：刚体各点的运动轨迹都在平行平面内。

#### 速度关系（基点法）

取质心 $C$ 为基点，刚体上任一点 $P$ 的速度：

$$\vec{v}_P = \vec{v}_C + \vec{\omega} \times \vec{r}_{CP}$$

其中 $\vec{r}_{CP}$ 是从质心指向 $P$ 的位矢。

#### 纯滚动条件

当刚体在表面上做纯滚动（无滑动）时：

$$v_C = \omega R$$

其中 $R$ 是滚动体的半径。接触点瞬时速度为零。

#### 瞬时速度中心（瞬心）

纯滚动中，接触点即为**瞬心**（瞬时速度为零）。刚体在该瞬时的运动等价于绕瞬心的纯转动。

### 3.3.2 经典模型分析

#### 纯滚动圆柱/圆球沿斜面滚下

半径为 $R$ 的圆柱（或圆球）在倾角为 $\theta$ 的斜面上纯滚动。

- 平动方程：$mg\sin\theta - f = ma_C$
- 转动方程：$fR = I_C\,\alpha$
- 纯滚动约束：$a_C = R\alpha$

联立解得（以圆盘 $I_C = \frac{1}{2}mR^2$ 为例）：
$$a_C = \frac{g\sin\theta}{1 + \frac{I_C}{mR^2}} = \frac{2}{3}g\sin\theta$$

比较：若为光滑斜面（无滚动），$a = g\sin\theta$。纯滚动时加速度较小，因为有部分能量转化为转动动能。

## 3.4 刚体的进动

### 3.4.1 基本公式

**进动**（precession）：高速自转的陀螺在外力矩作用下，自转轴绕竖直轴旋转。

进动角速度：
$$\omega_p = \frac{M}{I\omega} = \frac{mgr}{I\omega}$$

其中 $M$ 是外力矩大小，$I$ 是对自转轴的转动惯量，$\omega$ 是自转角速度。

**物理解释**：力矩方向始终垂直于角动量方向，使角动量方向改变但大小不变。

### 3.4.2 经典模型

**陀螺进动**：陀螺自转很快时，近似认为 $\vec{L} \approx I\vec{\omega}$（沿自转轴方向），外力矩 $\vec{M} = \vec{r} \times m\vec{g}$（水平方向），$\vec{M} = \frac{d\vec{L}}{dt}$ 使得自转轴绕竖直方向进动。

进动角速度：$\Omega = \frac{mgr}{I\omega}$

## 核心提醒

- **转动惯量取决于转轴位置**，同一物体绕不同轴转动惯量不同
- 平行轴定理非常重要：$I = I_C + md^2$
- 纯滚动的约束条件 $v_C = \omega R$ 连接了平动和转动
- 分析刚体动力学时，**对质心列转动方程 + 对整体列平动方程**是标准做法
- 瞬时速度中心（瞬心）在纯滚动中即接触点
